# Сопроводительная документация

## Что сделано

- Исправлена фильтрация характеристик по выбранным категориям.
- Общие характеристики отображаются без выбранных категорий и добавляются к характеристикам выбранных категорий.
- Устранено дублирование характеристик при выборе нескольких категорий.
- Добавлена поддержка числовых характеристик в AJAX-ответе.
- Входные ID категорий валидируются, SQL-запрос использует параметры PDO и `FIND_IN_SET`.
- Значения из базы данных экранируются перед выводом в HTML.
- Реализовано сохранение введённых значений после AJAX-обновления: текстовые поля, числовые поля, select и checkbox.
- Исправлен сбор данных для отправки: категории передаются по `chpu_category`, заполненные характеристики — по ID, значения мультивыбора соединяются через `:::`.
- Пустые значения не отправляются, числовое значение `0` сохраняется.
- Существующие URL, форматы запросов, DOM-классы, схема и данные базы не изменялись.

## Проверка

Синтаксис PHP-файлов проверен через `php -l`, JavaScript — через проверку синтаксиса Node.js. Дополнительно выполнена проверка `git diff --check`.

Автоматические проверки запускаются из корня проекта:

```bash
docker compose up --build -d
docker compose exec -T web php /var/www/tests/run.php
```

Тесты проверяют:

- доступность тестовой базы;
- HTML-контракт AJAX-обработчика;
- вывод общих характеристик без категории;
- фильтрацию для категории «Мебель»;
- отсутствие дублей при нескольких категориях;
- обработку некорректных категорий и экранирование HTML.

Сохранение значений после AJAX и сбор итогового payload дополнительно проверены вручную через браузер.

## Совместимость

Решение сохраняет совместимость с PHP 5.6, MySQL 5.7 и jQuery 1.12.4. Новые frontend-фреймворки и изменения схемы базы данных не добавлялись.
